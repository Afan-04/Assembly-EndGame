# 🔤 Assembly: Endgame

A hangman-style word game built with React. Guess the word within 8 attempts
to keep the programming world safe from Assembly!

## Features
- Random word chosen from a built-in word list on every new game
- Each wrong guess eliminates a programming language, with a random farewell message
- On-screen keyboard that marks correct and wrong guesses and locks when the game ends
- Confetti on a win; the answer is revealed when you lose
- Accessibility support: aria-live status updates, screen-reader-only text, labeled keys

## Tech Stack
React 18 · Vite · clsx · react-confetti · CSS

## Getting Started
npm install
npm run dev
